# Prisma
Este repositório contém o desenvolvimento inicial de uma ferramenta de organização financeira baseada em agentes. 
A proposta explora a reflexão sobre se a inteligência artificial irá substituir o humano ou ampliar o seu potencial. 

## Requisitos Arquiteturais:
- O sistema deve ter pelo menos 2 agentes que trabalhem juntos.
- O projeto deve ter uma base de conhecimento.
- É obrigatório aplicar MLOps.
- Deve-se construir e testar pelo menos uma rede neural simples.
- O sistema precisa utilizar API por meio dos agentes.
- O desenvolvimento deve utilizar alguma ferramenta de versionamento de código.
- O objetivo é desenvolver uma solução ética e explicável.
- É necessário ter pelo menos 1 resource como base de projeto com até 2 anos de publicação.
- A entrega final deve ser um MVP funcional.
